切片定义（世界坐标轴：X=沿轨 / Y=跨轨14通道 / Z=深度）

| 视图 | 取法 | 显示平面 | 实际内容 |
|---|---|---|---|
| **B-Scan** | **固定通道 Y=k**（k=0..13，由通道滑块选） | **(X, Z)** 二维切片 | 单通道的雷达剖面图（radargram）：横轴沿轨距离、纵轴深度 |
| **C-Scan** | **固定深度 Z=k**（L0 深度样本 0..780，由深度滑块选） | **(X, Y)** 二维切片 | 某个深度上的水平切片：横轴沿轨、纵轴跨轨的 14 通道全幅图 |

也就是说：
- **B-Scan 取的是「某一条通道」的 (距离, 深度) 截面** → 屏幕上横是沿轨、竖是深度，像经典雷达图。
- **C-Scan 取的是「某一个深度」的 (距离, 通道) 截面** → 屏幕上横是沿轨、竖是 14 个通道（跨轨位置）。

## 数据怎么来（不是重新请求）
`sliceView.js:3` 的注释明确写了数据源：**已加载 mesh 的 `Data3DTexture.image`（Float32Array）**，不重复拉取、不加第二套缓存。

- 体积数据经 `tileLoader` 解压成 int16 → 渲染成 Float32 纹理挂到 mesh 上；切片视图把**当前已加载的所有瓦片**按「粗级→细级」顺序 stamp 进固定分辨率网格（细级覆盖粗级，越细越清晰），再用与 3D 体渲染**同一套 Style**（`gain → normalize → gamma → threshold → colorMap`）映射到 2D canvas 上。
- 分辨率上限：沿轨方向 X 截到 **2048**（源是 45307 道，显示足够）；B-Scan 深度方向用满 **781** 样本；C-Scan 通道方向就是 **14**。

## 和图例对应的滑块
- `chanSlider`（通道 0..13）→ 控制 B-Scan 的 Y=k
- `depthSlider`（L0 深度 0..780）→ 控制 C-Scan 的 Z=k

一个值得注意的点：C-Scan 的深度序号是 **L0 样本号**，所以无论相机在哪级 LOD，深度滑块都直接对应原始 781 样本深度；而 B-Scan 里细/粗级瓦片的体素会按各自的 `spacing` 足迹铺满网格，近处看细、远处看粗。
